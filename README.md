# SuryaNamaskar-Live-Pose-Detection-System-by-using-Machine-Learing 
A Deep learning model is proposed which uses LR algorithm for yoga 
pose identification along with a human joints localization model 
followed by a process for identification
of errors in the pose for developing the system. After obtaining all
the information about the pose of the user the system gives feedback
to improve or correct the posture of the user. we propose an im
proved algorithm to calculate scores that can be applied to all poses.
Ourapplication is evaluated on different Yoga poses under different
scenes, and its robustness is guaranteed.
Keywords: Yoga, OpenPose, Pose Assessment,Machine Learning,
Classification
